# 备案等待期间可完成工作清单

更新日期：2026-08-05

## 高优先级

- [x] 固定生产代码、镜像 digest、回滚分支和实例环境变量权限。
- [x] 部署文件同步时排除 `.env.production`，并对同步前后校验和，防止实例密钥被模板覆盖。
- [x] Docker 五服务健康检查、资源限制、日志大小限制和 `unless-stopped` 自动重启。
- [x] MySQL、Redis、MongoDB 内网隔离、认证、持久化与 2C2G 参数优化。
- [x] 每日 MySQL/MongoDB/Redis 备份、SHA-256 校验、14 天保留和并发锁。
- [x] 每 5 分钟执行源站、容器、数据库、磁盘和内存健康检查。
- [x] Nginx/后端文件日志轮转，Docker JSON 日志轮转。
- [x] SSH 密钥登录、禁用密码、UFW、Fail2ban、自动安全更新和最小端口开放。
- [ ] 配置异地对象存储备份；需要用户确认存储账号、地域、费用和凭据管理方式。
- [ ] 在隔离环境执行一次完整恢复演练；生产机 2C2G 不适合同机启动第二套数据库。

## 中优先级

- [x] 生产部署、健康检查、备份恢复、回滚和故障排查文档。
- [x] 模板保留商家 AppID、店铺、地图、隐私和支付字段占位符，在线支付默认关闭。
- [x] 密钥扫描、模板边界检查、构建和上传前检查脚本。
- [x] 商家接入、菜单导入、餐桌码、部署和售后标准流程。
- [ ] 配置外部可用性告警；需要用户指定短信、邮箱或告警 Webhook 接收方。
- [ ] 商家真实资料、菜单价格和最终预览确认；属于每家商户独立交付内容。

## 低优先级

- [ ] 商家数量和订单量增长后再引入 Prometheus、Grafana、集中日志和数据库只读副本。
- [ ] 50 家以上再评估服务器扩容、负载均衡和托管数据库，不在当前 2C2G MVP 阶段过度设计。

## 必须等待 ICP 备案

- 公网 HTTPS 证书签发和 Nginx HTTPS 模板切换。
- 微信 request/uploadFile/downloadFile/socket 合法域名配置与真机网络验收。
- 正式公网顾客端、老板端、WSS 全链路验收。
- 完成以上项目后，才可进入 Phase 6.5 的真实微信支付、真机扫码和正式上传。
