# Phase 6.4.1 报告

更新日期：2026-08-05

## 已完成

- 生产 Docker、数据库、缓存、Nginx、资源限制、持久化、自动重启和健康检查基线。
- 每日自动备份、备份校验与保留策略；每 5 分钟本机健康监控；项目日志轮转。
- SSH/UFW/Fail2ban/自动安全更新、端口与数据库网络隔离。
- 餐饮 SaaS 母版的商家责任边界、敏感信息隔离、初始化/导入/部署/回滚文档和检查脚本。

## 无需备案但仍需外部条件

- 异地备份：需要独立对象存储账号、地域、费用和凭据授权。
- 外部告警：需要短信、邮箱或 Webhook 接收方。
- 隔离恢复演练：建议使用独立测试机，避免在 2C2G 生产机争抢资源。
- 每家商户的真实资料、菜单、类目、隐私和最终预览确认。

## 必须等待备案

- SSL 证书、TLS 生产切换、HTTP 到 HTTPS 跳转验证。
- 微信合法域名和 WSS 配置。
- 公网顾客端、老板端、真机扫码与正式上线验收。

## 结论

Phase 6.5 未开始。备案完成后只执行证书部署、微信后台域名配置和公网验收；全部通过后才能进入真实支付与正式上线。
