# 管理员操作手册

## 创建新商家

1. 登录平台管理后台。
2. 打开“门店管理 → 创建商家”。
3. 填写店铺基础信息及老板登录账号。
4. 提交后记录返回的 `merchantId`、`shopId`、老板账号。
5. 临时密码只通过安全渠道交付，不写入工单、群聊或文档。

系统会在同一事务中创建老板账号、店铺、账号与店铺绑定。任一步失败都会回滚；新店默认休息中、店内消费、支付未启用。

## 商家上线检查

1. 店名、Logo、联系方式和营业时间。
2. 分类、菜品、价格、图片和上下架状态。
3. 餐桌编号、场景码和打印后的二维码。
4. 商家自己的 AppID、商户号及服务端支付配置状态。
5. 请求域名、隐私指引、餐饮类目及相关资质。
6. 扫码、购物车、下单、支付、接单、完成、统计全流程。

## 数据隔离规则

- 管理员创建时生成 `shopId`；老板业务接口从登录 Token 获取绑定店铺。
- 不允许用前端传入的 `shopId` 作为权限依据。
- 支付配置、订单、菜品、餐桌、统计均按订单或登录会话的店铺隔离。

## 禁止操作

- 不替商家确认主体、证照、隐私目的或资金责任。
- 不把 AppSecret、APIv3 Key、商户私钥、证书、上传私钥放入代码或数据库明文字段。
- 不在未完成商家确认时启用支付、上传或提审。
- 不将已填写的门店实例配置覆盖回可复用母版。
