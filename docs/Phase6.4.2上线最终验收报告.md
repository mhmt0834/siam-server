## 上线风险

### 不阻塞少量商家试运营，但应跟踪

1. `tb_order_detail` 只有主键，缺少 `order_id` 索引；订单明细和统计数据增长后可能全表扫描。
2. 统计按 `order_completion_time` 过滤，现有订单索引第三列是 `create_time`；应在真实数据增长前评估 `(shop_id,status,order_completion_time)`。
3. Nginx 单 IP 限流在同一公网 NAT 下可能误伤高峰顾客，建议试运营后根据日志调整，并考虑把限流响应从 503 改为 429。
4. 2G 内存适合少量商家起步；持续高峰或引入更多组件前应升级至 4G。
