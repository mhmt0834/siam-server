# 数据库设计

基线结构：`sql/mysql/siam_db.sql`；幂等迁移：`sql/mysql/update.sql`；Phase 1 验收快照：`docs/phase1-acceptance/schema-phase1.sql`。

```mermaid
erDiagram
    TB_SHOP ||--o{ TB_DINING_TABLE : owns
    TB_SHOP ||--o{ TB_MENU : owns
    TB_SHOP ||--o{ TB_GOODS : owns
    TB_MEMBER ||--o{ TB_SHOPPING_CART : owns
    TB_SHOP ||--o{ TB_SHOPPING_CART : isolates
    TB_DINING_TABLE ||--o{ TB_SHOPPING_CART : isolates
    TB_MENU ||--o{ TB_MENU_GOODS_RELATION : contains
    TB_GOODS ||--o{ TB_MENU_GOODS_RELATION : belongs
```

`tb_dining_table` 使用 `(shop_id, table_no)` 和 `scene_token` 唯一约束。`tb_shopping_cart` 使用 `member_id + shop_id + dining_table_id` 确定唯一业务上下文。所有老板端资源通过登录 Token 获取商家和 `shop_id`，不信任前端传入的 `shopId`。

详细字段、索引及两次迁移结果见 [Phase 1 数据库说明](phase1-acceptance/DATABASE.md) 和 [迁移日志](phase1-acceptance/logs/migration-run-1.log)。
