# 玉KING智能点餐 - 温暖美食风格 UI 改造计划

## 设计规范

| 要素 | 当前值 | 目标值 |
|------|--------|--------|
| 主色 | `#111111` 深黑 | `#4A2605` 深棕 |
| 强调色 | `#B89555` 金色 | `#F05A2A` 橙红 |
| 背景色 | `#F5F5F3` 冷灰 | `#F8F6F2` 暖米 |
| 卡片色 | `#FFFFFF` 白色 | 保持白色 |
| 价格色 | 黑色 | `#F05A2A` 橙红 |
| 风格 | 极简黑白 | 温暖食欲系 |

- `.loading_box_class`: `#111111` → `#4A2605`

- 导航栏背景色统一切换

  - 优惠活动卡片：从满减 API 获取数据
- **保留**：轮播逻辑、API 调用方法、下拉刷新

### 具体改动
- **左侧分类栏**：
  - 移除当前深黑主题背景
  - 选中态：浅米色背景 + 左侧深棕竖线指示器
  - 文字颜色：选中深棕，未选中灰色
- **右侧商品列表**：
  - 商品卡片：白色背景 + 圆角图片 + 名称/描述/价格
  - 价格使用橙红 `#F05A2A`
  - "+" 按钮：深棕圆形，已选商品用 "− N +" 步进器
  - 招牌标签：橙红胶囊角标
  - 分隔线使用浅灰
- **底部购物车栏**：
  - 深棕色(`#4A2605`)大胶囊形状
  - 白色购物车图标 + 橙红数量角标
  - 金额显示 + "去结算"按钮（浅米白文字）
  - 大圆角 + 柔和阴影
- **移除**：顶部自提/外送切换区域（简化流程）

- **金额明细**：费用拆分明细卡片，合计用橙红大字
- **底部按钮**：深棕大圆角 + 协议文字
