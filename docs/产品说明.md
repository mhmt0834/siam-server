# 餐饮 SaaS 母版产品说明

版本：`restaurant-saas-template-v1.0`

本版本完成 Phase 1：餐桌管理、桌码场景解析、门店菜单、购物车及 `shop_id`/餐桌/会员隔离。老板端可维护本店餐桌，用户端扫码后进入对应门店和桌号，异常桌码显示“二维码无效，请重新扫码”。

订单、微信支付、实时接单和订单状态流转属于 Phase 2，本版本不声明已实现。

模板只提供通用代码、数据库结构、初始化数据、迁移和文档。正式 AppID、AppSecret、HTTPS 域名、地图 Key、支付密钥、商户证书、商家资料及隐私确认必须由商家实例独立配置，不得同步回模板。
