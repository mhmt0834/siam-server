# 二次开发指南

1. 从 `restaurant-saas-template-v1.0` 创建新项目分支，不直接修改正式标签。
2. 先运行 `scripts/check-template-boundaries.ps1` 和 `scripts/check-secrets.ps1`，确认模板无实例数据和密钥。
3. 所有业务表和查询保持 `shop_id` 隔离；老板端 `shopId` 必须从 Token 推导。
4. 商家实例配置使用环境变量或忽略提交的本地文件；仅可把通用结构和无实例数据的改进同步回模板。
5. 数据库变更写入幂等迁移，连续执行两次并验证结构、索引和存量数据。
6. 用户端改动后用 HBuilderX 全量编译，验证普通启动、无效桌码、有效桌码、购物车跨桌隔离及 Console。
7. 发布前运行 `scripts/preflight-release.ps1 -RequireBuildArtifacts`，再由商家管理员使用正式 AppID 上传。

不得把商家正式 AppID、支付配置、隐私确认、域名、地图 Key 或经营数据写入母版。
