# 部署教程

1. 安装 JDK 8、Maven、MySQL 8、Redis、MongoDB 4.4、Node.js、HBuilderX 和微信开发者工具。
2. 复制 `application-local.example.yml` 为忽略提交的实例配置，填写数据库地址；密钥使用环境变量或实例私有配置。
3. 新库先导入 `sql/mysql/siam_db.sql`，再执行 `sql/mysql/update.sql`；升级只执行可重复运行的 `update.sql`。
4. 构建后端：`mvn -pl siam-system/system-provider -am -DskipTests package`，启动后检查 `/siam-server/actuator/health`。
5. 按现有流程构建 `vue-siam-shop`；用 HBuilderX 将 `uniapp-siam-user` 编译到微信开发者工具。
6. 微信开发者工具使用基础库 `3.16.2`、关闭热更新并默认“普通编译”。本地 API 为 `http://127.0.0.1:9200/siam-server`；生产必须改为已备案并在微信后台配置的 HTTPS 域名。
7. 本地模拟桌码可把调试条件中的 `__SCENE_TOKEN__` 临时替换为测试场景码，完成后恢复占位符；无正式 AppID 时仍可使用测试号调试，上传前必须换商家正式 AppID 并真机验收。

上线实例不得提交 AppSecret、支付密钥、证书、地图 Key 或隐私确认。详细依赖及边界见 [Phase 1 部署说明](phase1-acceptance/DEPLOYMENT.md)。
