# 商家接入手册

## 责任边界

- 商家负责小程序主体、餐饮资质、菜单与价格真实性、隐私说明、微信商户号和资金结算。
- 授权开发管理员负责复制母版、技术配置、测试、构建，以及商家确认最终预览后的上传。
- AppSecret、支付密钥、证书、上传私钥、证照原件不得进入前端、Git、日志、聊天或母版。

## 一天上线标准流程

```text
管理员创建商家
→ 记录 shopId 和老板账号
→ 老板完善店名、Logo、营业时间、公告、联系方式
→ 服务端配置该店微信支付（未完成时保持关闭）
→ 批量上传菜单
→ 创建餐桌并生成二维码
→ 商家核对页面、价格、隐私和支付
→ 构建并由授权管理员上传
```

## 创建商家

1. 管理后台进入“门店管理 → 创建商家”。
2. 填写店铺名称、联系方式、营业时间和老板账号。
3. 设置不少于 8 位的临时密码，通过安全渠道单独交给老板。
4. 创建成功后记录 `shopId`。新店默认“休息中”，不会立即对外营业。

## 店铺基础配置

老板登录后进入“门店管理 → 门店基本信息”，可维护店铺名称、Logo、营业时间、公告、联系方式及营业状态。接口从登录会话取得 `shopId`，页面不得自行指定其他店铺。

## 菜品快速导入

“商品管理 → 商品列表 → 批量添加”支持一次提交最多 500 个菜品：名称、图片地址、分类、价格、状态和介绍。不存在的分类会在当前店铺下自动创建。

Excel 预留接口仅接受 `.xlsx`。表头必须包含：

```text
商品名称、商品类别、状态、一口价、包装费、商品描述、介绍图片、打印机编号、打印次数
```

介绍图片需嵌入对应单元格；状态为“待上架、已上架、已下架、售罄”之一。建议先用 2 条数据试导，再导入完整菜单。

## 上线验收

- 桌码能解析正确店铺和桌号，跨桌购物车不混用。
- 菜单图片、分类、价格和上下架状态正确。
- 支付进入商家自己的商户号；未配置时前端不展示支付入口。
- 老板能接单、完成订单，并在经营概览看到真实统计。
- 商家确认隐私、类目、资质及最终预览后，授权管理员才执行上传。
